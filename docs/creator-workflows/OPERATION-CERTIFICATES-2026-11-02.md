## Implementation contracts

Video edit reuses `verifiedMediaProbes`; it does not trust uploaded metadata. The source certificate binds project/asset/storage ID, canonical Storage SHA256/size, measured dimensions/duration and audio presence. The quote uses `ceil(full source seconds) * live cents_per_second_output /100`; shot trim does not reduce reservation. Editing rejects extra references, first/last frames, masks, generated audio, output resolution, continuation and upscale controls. `SILENT` needs a separate explicit composition mute operation; the provider's preserved audio is not silently discarded.

Create and fence independently resolve canonical source facts. Job request JSON contains `editSource/editQuote` or `continuationQuote`; incoming forged certificates are ignored. The worker fetches fresh catalog controls/prices before the existing submission fence. A changed source, withdrawn approval/quarantine, quote, operation SKU, fingerprint or stale proof prevents the first paid POST. Already accepted jobs retain their polling path and do not purchase replacements.

New `verifiedAudioProbes` is separate from video dimensions. Its internal-only writer records canonical checksum/size, actual duration, codec, sample rate, channels and `hasVideo`; project access, current approved production and exact selected audio source are checked before probing. Audio-only input is required. The 64 MiB cap is the local probe's resource limit, not a claim about Avatar IV provider limits. No Avatar spend contract is derived from it.

Proposed next single-voice contract: an explicit `primaryVoiceSampleAssetId` in preparation authoring/request, selected from the approved, consented voice samples and revalidated against current consent at creation and fence. A single narration voice should not silently discard additional requested references or pretend multiple numbered Seed voices are enrollment samples. This field and its picker are not implemented in this packet. Multi-speaker turns and transcript/image conditioning require their own shared request contracts.
