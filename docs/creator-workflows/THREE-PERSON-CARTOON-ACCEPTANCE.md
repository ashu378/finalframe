## Scope

The source was prepared through canonical generation actions, not through the browser. The conversion, approvals, audio extraction, timeline restoration and export use the normal authenticated interface against online Convex `knowing-snail-785` and the existing FinalFrame renderer.

This is a scoped source-performance-preservation test. It does not certify arbitrary multi-person speech replacement, perfect phoneme-level lip sync, or independent human creative/listening approval. Sampled source and output frames show corresponding speaking turns and preserved placement, clothing, camera and gestures. The center performer already has some open-mouth reactions in the source; retaining that behavior is not proof that a provider can repair every source performance.

## Fix

The strict production-planning schema previously omitted shot operation, so a correctly worded source-edit plan persisted as generic generation. That wrongly demanded newly created character references. The planner now emits GENERATE or EDIT explicitly, canonical shot persistence preserves that operation, and conflicting top-level/metadata values fail rather than silently routing elsewhere. The director instructions explicitly preserve each source speaker’s mouth timing and avoid assigning speech to listeners.

The already-paid draft was corrected using the existing Video operation control, then approved normally. No plan or video was repurchased. Existing dedicated portrait-speech metadata remains compatible. The duration-planning test harness was updated for the existing UGC brief dependency.
