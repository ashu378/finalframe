## Regional workflow proposal: deterministic replacement composite

There is no portable OpenRouter mask field, and current FLUX Edit passthrough exposes only `safety_tolerance`. FinalFrame can implement a separate application workflow: render source `S`, aligned prompt-edited result `E`, and an explicitly authored mask `M` as `M*E + (1-M)*S`. This guarantees source pixels outside zero-alpha mask before encoding; lossy exported video does not preserve those pixels bit-for-bit. It provides regional replacement, not native generative inpainting or a promise that the model obeyed regional attention.

Existing renderer `types.ts`, `manifest.ts` and assembly planning have no mask asset/compositing contract; the existing `clipPath` is only a wipe transition. Shared design must define immutable project-bound source/edit/mask references and checksums, pixel grid/timebase/alignment, static versus tracked masks, frame coverage, feathering and inversion, explicit audio reuse, approval/version provenance, resource limits and render billing. Dynamic subjects need authored/tracked masks or rotoscoping. Reject missing frames, foreign/changed assets and mismatched time/dimensions. Test pre-encode outside-mask equality, moving boundaries, blend edges and source audio; inspect visual continuity with synthetic fixtures. Full-source FLUX cost still applies. No implementation is authorized without that shared contract discussion.
