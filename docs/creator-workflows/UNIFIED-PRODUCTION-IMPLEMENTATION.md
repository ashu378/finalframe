# Unified FinalFrame production workflow

Approved scope: the owner's 12 November workflow attachment. Complete functionality before redesign, email verification/recovery and payments. Preserve project isolation, approved snapshots, retained media, canonical productions/productionVersions, online development Convex, OpenRouter-only AI and the $25 cumulative test ceiling. No Yafpay changes.

## Implementation checkpoints

1. **Creation intent and involvement.** Distinguish Create / Improve footage / Focused tool; video purpose from visual treatment; source mode from reusable recipe. Store validated versioned intent in canonical input and audited project preferences. Switching involvement does not grant spending or approve assets. Retain deliberately selected footage on reload and revision.
2. **One production journey.** Brief → Script → Creative guide → Storyboard → Takes → Edit/sound → Review → Export. Every link preserves the selected production and explicit edit version. Persisted plan stages show actual canonical artifacts, not duplicate planning tables or synthetic completion badges.
3. **Visual storyboard and direction.** Immutable same-project image candidates, explicit selected frame, actual ordered scenes/shots, draft CRUD and camera/lighting/action controls. Canonical approval freezes exactly the same source proof into graph rows and production snapshot. Queued takes record the consumed frame and authored shot hash. Approved work changes through a no-cost canonical draft copy; earlier versions remain readable.
4. **Image previews and angles.** Explicit quote and confirmation for one new still/edit or four image-conditioned camera alternatives. Use central reviewed image-model configuration and current catalog controls/pricing; include input images, output count and all reservations. Four alternatives remain image candidates, never four unwanted shots. Keep originals. No mask/exact-preservation guarantees invented from a prompt.
5. **Connected transformations.** Reuse existing video-operation contracts for motion transfer, appearance/character/object edits and original-audio finishing. Clearly distinguish still edits, source-video edits and newly generated interpretations. Missing required controls stop before purchase; no public control should masquerade as a certified route.
6. **Director coordination.** Use the existing canonical planner, resource preparation, durable recipe nodes, generation jobs, timeline and renderer rather than a second agent/job system. Beginner production preparation derives from the exact approved plan and explicit references. Existing estimates authorize paid stages separately. A first-cut preview uses real ordered media and timing; explicit human review can approve only its exact bound saved results before the existing timeline/export gates. Detailed manual shot controls remain available.
7. **Durable dependency/revision safety.** Record owned frame → authored shot → exact take → timeline clip → exact timeline lineage. New writes freeze source hashes. Revalidate consumed endpoints at assembly, preserve legacy meanings, reject stale selected inputs and ignore unrelated abandoned branches. Never re-certify an old take against changed camera, lighting or resource bindings.
8. **Verification and deployment.** Run focused authorization/version/cost/recovery contracts, full typecheck/lint/build, online development integration, and ordinary Preview browser journeys. Inspect actual candidate/output media; mocks and catalog listings cannot certify creative quality. Deploy additive readers/schema before new clients. Reconcile receipts before serial controlled paid samples. Preserve all prior evidence and uncertainty.

## Acceptance cases

- All three entry paths persist source mode, purpose/style and involvement independently.
- Viewing a route does not mutate data, approve work or purchase media.
- Switching involvement preserves approved versions, source media, permissions and budget.
- Storyboard cards contain actual project images and exact saved take links; unknown or unavailable images remain explicit.
- Frame selection, direction changes and shot edits respect draft/locked state and optimistic concurrency.
- Approved-to-draft copy is no-cost, idempotent, retains old frames, and refuses to overwrite a newer unrelated draft.
- Four-angle confirmation freezes four prompts, exact same-project source bytes, current model/config and combined ceiling; duplicate confirmation returns existing jobs.
- Replacing/revoking a quoted source or changing catalog controls prevents the first purchase. Accepted jobs retain their original IDs and outputs.
- Selected candidate direction reaches the canonical video prompt, snapshot and take context. Newer failed takes cannot silently replace the selected timeline take.
- A changed upstream direction marks only actual consumers; unrelated approved material and old exports are unchanged.
- Beginner first-cut review binds actual ordered media/ranges to a server hash, requires explicit review, and cannot approve timelines/exports or authorize another paid stage.
- Review a cartoon comedy, product advertisement and cinematic scene with real images/audio and downloaded outputs. Retain any creative failures and human-language/provider dependencies honestly.

## Migration and rollback

New candidate/estimate tables and optional dependency proofs are additive. No retained data is deleted or remapped. Legacy plans without creator intent, storyboard frames or authored dependency hashes keep compatibility reads. New copied drafts use independently scoped candidate IDs. Roll back by restoring the previous compatible Preview/backend and pausing new requests; retain accepted jobs, receipts, uncertainty, candidates, drafts and exports.

## Director responsibilities and actual artifacts

Specialist responsibilities share one canonical production and durable recipe. They do not each make redundant model calls.

| Responsibility | Existing/connected execution | Artifact consumed by the next stage |
|---|---|---|
| Brief, script and story | Structured planning through the central text gateway and canonical productions | Saved plan, script/scene beats and immutable approved version |
| Art direction | Project creative guide, approved resource versions and quoted storyboard image preparation | Approved image assets and immutable storyboard candidates |
| Cinematography | Typed storyboard direction, composition selection and canonical shot request | Selected frame, camera/lighting/action fields and frozen authored source hash |
| Continuity | Canonical continuity resolvers and versioned resource bindings | Approved bible, cast/voice IDs and source-version snapshots |
| Generation/recovery | Existing durable generation jobs, receipts, submission fences and leases | Saved takes, exact provider usage and recoverable outcomes |
| Picture editing | Existing recipe dependencies and canonical timeline functions | Exact take placements, trims and timeline versions |
| Sound/captions | Existing preparation, decoded timing verification and finishing contracts | Saved narration/music, checksum-bound timing and reviewed caption resources |
| Quality review | Exact first-cut media projection plus existing technical checks and explicit human approvals | Specific blocked checks, review-bound source hash and auditable decisions |
| Delivery | Existing canonical manifest, secure asynchronous renderer and export | Verified Storage-backed downloadable output |

The first-cut player is a review of actual saved media, not a claim that an MP4 has already been rendered. Graphics, caption design, transitions and the final locked edit continue through their existing explicit editor/review/export gates. Missing verified sound timing can be checked without buying narration again; measurement does not approve a recording.
